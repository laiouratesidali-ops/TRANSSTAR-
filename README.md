## Overview
A professional, high-performance web dashboard developed for **TRANSSTAR LAIOURATE**, a specialized logistics and transport company. This application serves as an advanced internal tool for managing logistics operations and dynamically generating professional financial documents.

## Key Features
* **Dynamic Invoice Generator:** Real-time billing tool that instantly calculates unit prices, quantities, VAT (19%), and total TTC.
* **Print & PDF Export:** One-click functionality to generate clean, print-ready PDF invoices without UI clutter.
* **Modern Dashboard Interface:** A highly responsive, sleek, and dark-themed sidebar layout.
* **Fast & Optimized:** Built with Astro for lightning-fast loading speeds and zero JavaScript overhead where not needed.

## Tech Stack
* **Core Framework:** [Astro](https://astro.build/)
* **UI & Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Icons:** FontAwesome
* **Deployment:** CI/CD via [Netlify](https://www.netlify.com/)
